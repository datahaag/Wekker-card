# Mediavoorbeelden

| Gebruik | URI/ID (voorbeeld) | Mediatype |
|---|---|---|
| Directe radiostream | `https://radio.example.org/live.mp3` | `music` |
| Spotify-link | `https://open.spotify.com/album/...` | `music` |
| Spotify-URI | `spotify:playlist:...` | `playlist` |
| Sonos-playlist | naam van de playlist | `playlist` |
| Sonos-favoriet | `FV:2/31` | `favorite_item_id` |

Voorbeeldadressen zijn placeholders en spelen niet noodzakelijk. Gebruik een URI die jouw Sonos zelfstandig kan bereiken.
