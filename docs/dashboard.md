# Dashboard

Na het toevoegen van de integratie is **Wekker-card (Sonos retro)** beschikbaar in de kaartkiezer. Plaats hem op elk gewenst dashboard of gebruik:

```yaml
type: custom:wekker-card
```

Alle kaartinstanties gebruiken dezelfde integratie-entiteiten. De kaart bevat een tabblad **WEKKER** en een apart tabblad **INSTELLINGEN**.
